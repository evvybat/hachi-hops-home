THE OTHER NANA'S ARTWORK (Nana Osaki)
=====================================

Put her sprites in this folder and the game uses them automatically, with no
code changes. Refresh the browser after adding them.

  idle.png    waiting for Hachi          <- REQUIRED. Without it the game keeps
                                            the built-in drawn Nana.
  happy.png   shown once Hachi has all the shopping bags (optional)

Where she appears: Level 3 (waiting with the shopping bags). More levels will
use her too (the Shinkansen in Level 1, the party in Level 4).

How to make them (same as Hachi's)
  - PNG (or WebP) with a TRANSPARENT background. A JPEG can't be transparent,
    so save the final image as PNG, or tell me and I'll cut the background out
    like I did for Hachi.
  - Draw her FACING RIGHT. The game turns her to face Hachi.
  - Feet touching the BOTTOM edge of the image, and crop every pose to the
    SAME box so she doesn't shift.
  - Around 300-500px tall is plenty.

She is shown the same height as Hachi (SPRITE_HEIGHT in static/js/sprites.js).
